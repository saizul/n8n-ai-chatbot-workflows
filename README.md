# n8n AI Chatbot Workflows

Ready-to-import [n8n](https://n8n.io) workflows for AI sales and support chatbots:

- `ecommerce_ai_chatbot_workflow.json`: e-commerce AI assistant (Facebook Messenger + WhatsApp + WooCommerce orders)
- `facebook_book_ai_workflow.json`: Facebook Page AI chatbot for a book shop
- `whatsapp_book_ai_workflow.json`: WhatsApp Business AI chatbot (text + image)
- `Saizul Personal Ai.json`: personal AI assistant on Messenger

All credentials are placeholders (`YOUR_TOKEN` etc.); add your own in n8n Credentials after import.
